# Safari recovery upload
1. Unzip this package.
2. Select every file inside the folder.
3. Upload them to the root of the existing jos-one repository.
4. Commit directly to main with: Install JOS One Engineering 1.0.2 Flat Recovery
5. Wait about one minute.
6. Open https://6dhsf7y9zj-creator.github.io/jos-one/?v=102
7. If an older build remains, remove the Home Screen icon temporarily, open the URL in Safari, refresh, then add it to the Home Screen again.
